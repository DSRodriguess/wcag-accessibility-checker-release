# WCAG Accessibility Checker

Extensão para o Visual Studio Code desenvolvida para auxiliar na
identificação de possíveis problemas de acessibilidade em arquivos
HTML, considerando recomendações selecionadas da WCAG.

Esta versão está sendo disponibilizada para participação em uma
avaliação acadêmica realizada como parte de um Trabalho de Conclusão
de Curso de Ciência da Computação da UERJ.

## Funcionalidades

A extensão apresenta diagnósticos na aba Problems do Visual Studio
Code e oferece sugestões de correção, chamadas Quick Fixes, para
determinados problemas.

## Instalação

1. Acesse a seção Releases deste repositório.
2. Abra a versão mais recente.
3. Baixe o arquivo `wcag-accessibility-checker-0.0.1.vsix`.
4. Abra o Visual Studio Code.
5. Acesse a área Extensions.
6. Abra o menu de ações representado por três pontos.
7. Selecione `Install from VSIX...`.
8. Escolha o arquivo baixado.
9. Recarregue o Visual Studio Code, caso seja solicitado.

## Utilização

1. Abra o arquivo HTML disponibilizado para a atividade.
2. Clique em `WCAG Scan` na barra de status.
3. Abra a aba Problems para consultar os diagnósticos.
4. Realize as correções que considerar adequadas.
5. Utilize os Quick Fixes quando estiverem disponíveis.
6. Para abrir o painel, execute o comando `WCAG: Exibir painel`.

## Observação

A extensão auxilia na identificação de possíveis problemas de
acessibilidade, mas não substitui uma avaliação completa nem garante
conformidade integral com a WCAG.
